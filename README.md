# Web Vulnerability Scanner

A Python-based web vulnerability scanner built for educational purposes.

## Checks
- SQL Injection
- Cross-Site Scripting (XSS)
- Open Redirect
- Directory Traversal
- CSRF Token Detection
- Missing Security Headers
- Subdomain Enumeration

## Usage

## Example
python web_vuln_scanner.py http://testphp.vulnweb.com/listproducts.php?cat=1

## Disclaimer
Only scan systems you own or have explicit permission to test.
